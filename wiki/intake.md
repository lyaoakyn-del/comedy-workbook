# Intake

Buffer layer between active writing and canonical wiki.

**Use this for:** new observations, decisions, pattern recognitions that aren't ready to promote to a section hub yet.
**Don't use this for:** actual joke drafts (those go in `workbook/3-in-development/`).

After a compile run: promote `done` items to the relevant hub and clear them here.

---

## How to Add an Item

```
### YYYY-MM-DD — [brief title]
- status: new
- target: [which wiki file this should eventually go into]
- summary: [what was noticed / decided]
```

---

## Statuses

- `new` — not yet processed
- `in_progress` — being worked on
- `done` — promoted to canonical wiki file
- `rejected` — not useful, dropping
