# Рабочая тетрадь комика — система с AI

Практическая файловая система для разработки стендап-материала с AI как творческим партнёром. Построена и проверена на реальных открытых микрофонах.

> 🇬🇧 [English version](README.md)

---

## Что это такое

Структура папок и система промптов, которая превращает ежедневные наблюдения в отточенный стендап-материал. Никаких приложений, никаких подписок — только Markdown-файлы и AI comedy buddy, который знает твой голос.

Система следует естественному творческому пайплайну:

```
Утренние записи → Сырые идеи → Разработка шуток → Готовый материал → Сет-листы
        ↓                                                                   ↓
                         Еженедельная компиляция
                                  ↓
                wiki/ — AI-читаемый индекс всего материала
```

У каждого этапа — своя папка, шаблоны и чёткий критерий перехода на следующий уровень. Wiki-слой держит AI в курсе без необходимости читать сотни исходных файлов.

**Легко адаптируется** под другие творческие дисциплины с регулярным производством контента: подкасты, написание песен, проза.

---

## Зачем нужен wiki-слой

Через несколько месяцев ежедневных записей у тебя будет 200+ файлов. Без скомпилированного индекса происходит две вещи:

1. **AI теряется** — читает случайные файлы и не видит общей картины. Не знает, какие биты готовы к сцене, какие темы уже заезжены, где потенциал для колбэков.
2. **Ты теряешься** — забываешь что в разработке, теряешь из виду отложенный материал, каждый раз собираешь один и тот же сет вместо того чтобы строить на том, что работает.

Папка `wiki/` решает обе проблемы. Это скомпилированная, всегда актуальная карта твоего материала, по которой и ты, и AI ориентируетесь за секунды.

```
workbook/  →  компиляция  →  wiki/
(200+ файлов,                (5 индексных файлов,
 сырые и личные)              AI-читаемые)
```

AI читает `wiki/INDEX.md` первым, затем нужный section hub — и уже знает состояние всей твоей библиотеки материала до того, как ты задала первый вопрос.

## Быстрый старт

**1. Клонируй репо**
```bash
git clone https://github.com/YOUR_USERNAME/comedy-workbook.git
cd comedy-workbook
```

**2. Открой в редакторе**

Работает с любым Markdown-редактором. Рекомендуется [Obsidian](https://obsidian.md) — рендерит ссылки между файлами и даёт граф связей между материалом.

**3. Настрой AI buddy**

Скопируй содержимое `CLAUDE.md` в системный промпт своего AI (Claude Projects, ChatGPT custom instructions или любой LLM-интерфейс).

**4. Напиши первую утреннюю запись**

```bash
cp templates/morning-note.md workbook/2-ideas/morning-notes/$(date +%Y-%m-%d)_morning.md
```

Открой файл, пиши 10 минут без редактирования. Всё.

**5. Прочитай гайд**

Начни с [`guide/system-overview.md`](guide/system-overview.md).

## Ежедневный процесс

| Время | Активность | Куда |
|-------|-----------|------|
| Утро | Поток сознания без цензуры | `workbook/2-ideas/morning-notes/` |
| День | Расшифровка голосовых заметок | `workbook/2-ideas/audio-notes/` |
| Вечер | Разработка перспективного материала | `workbook/3-in-development/` |
| Неделя | Компиляция + ревью сет-листов | `wiki/` + `workbook/5-setlists/` |
| После выступления | Лог выступления, перевод готовых битов | `wiki/setlist-index.md` |

## Еженедельная компиляция

Раз в неделю (~20 минут) обновляй wiki, чтобы она отражала текущее состояние материала.

**Вручную:** следуй [`guide/compile.md`](guide/compile.md) шаг за шагом.

**С помощью AI:** вставь этот промпт:

```
Прочитай утренние записи этой недели в workbook/2-ideas/morning-notes/
и обновлённые файлы в workbook/3-in-development/.

Обнови section hubs в wiki/:
- wiki/morning-notes-hub.md: добавь новые повторяющиеся темы и перспективные наблюдения
- wiki/material-index.md: добавь новые биты, обнови статусы
- wiki/intake.md: обработай необработанные записи

Затем обнови дату в wiki/INDEX.md.
Не выдумывай материал. Компилируй только то, что есть.
```

AI делает работу. Ты проверяешь и коммитишь.

## Система тегов

| Тег | Значение |
|-----|---------|
| `#черновик` | Сырая идея, ещё не разработана |
| `#вработе` | Активно разрабатывается |
| `#проверено` | Выступил на сцене |
| `#колбэк` | Можно связать с другим битом |
| `#отложено` | Пока не работает, сохранить на потом |

---

## Критерий готовности шутки

Перед переносом из `3-in-development` в `4-ready`:
- [ ] Вызвала настоящий смех минимум 3 раза
- [ ] Setup чёткий и лаконичный
- [ ] Панчлайн работает без объяснений
- [ ] Тайминг отработан
